# Neko documentation

Neko is a small, general-purpose 2D game engine for Zig with pluggable
backends. Game code talks to one platform-agnostic API (`neko.*`) and the
backend (SDL2 on the desktop, gsKit on the PS2, …) is selected at build time.

Start here:

| Document | What it covers |
|----------|----------------|
| [como-funciona.md](como-funciona.md) | **explicação em português**: como a engine funciona por dentro |
| [godot.md](godot.md) | Godot → Neko mapping (code-first scenes, nodes, scripts) |
| [getting-started.md](getting-started.md) | install, wire the dependency, first program |
| [architecture.md](architecture.md) | how the engine is layered and built |
| [api.md](api.md) | namespace-by-namespace reference |

| [portability.md](portability.md) | hosted vs freestanding, and how to add a backend |

The executable API reference is generated by Zig:

```sh
zig build docs   # writes zig-out/docs/api/index.html
```
