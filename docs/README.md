# Neko documentation

Neko is a small, general-purpose game engine for Zig with pluggable backends.
Game code talks to one platform-agnostic API (`neko.*`) and the backend (SDL2 on
the desktop, gsKit on the PS2, …) is selected at build time.

Docs are grouped by purpose:
